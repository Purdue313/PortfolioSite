Technical Highlights

Outdoor GPS Wayfinding

Real-time GPS navigation across the Oregon Tech campus, integrating live map data to guide users between buildings with turn-by-turn directions.

Indoor Floor Plan Navigation

Custom indoor navigation system using embedded building floor plans, allowing users to navigate hallways and locate rooms within campus buildings.

React Native + Firebase

Cross-platform mobile frontend built in React Native with a Firebase backend handling real-time map data, building floor plans, and user sessions.

Full Agile Process

Developed across 3-week sprint cycles with rotating Scrum Master roles. Features tracked and managed in Jira throughout the project lifecycle.
