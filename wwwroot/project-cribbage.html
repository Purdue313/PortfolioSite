Technical Highlights

Complete Game Logic

Full implementation of cribbage rules including hand scoring, pegging phase, crib mechanics, pairs, runs, flushes, nobs, and go rules — all from scratch in C#.

Custom Card Deck

Independently designed a custom card deck with original artwork/assets, integrated into the UWP application for a polished visual experience.

UWP Desktop App

Built using the Universal Windows Platform framework, delivering a native Windows desktop experience with smooth UI interactions and state management throughout a full game session.
